# Fontes de Imagens - FitCore Pro

Este arquivo controla a origem das imagens usadas no repositório.

## Regra

Não usar imagem copiada de outro repositório sem licença clara.

Para cada imagem, registrar:

- nome do arquivo
- origem
- autor
- licença
- link
- pode usar comercialmente?
- precisa atribuição?

## Imagens iniciais

As imagens iniciais devem ser autorais ou placeholders.
