MVP-08 · Adapter de persistência

A API ganha caminho controlado entre JSON local e PostgreSQL.

Esta fase prepara a transição real do FitCore para SaaS: os MVPs continuam funcionando com fallback seguro, mas a arquitetura passa a ter um contrato claro para trocar o armazenamento sem quebrar a interface.

Contrato técnico

API → PersistenceAdapter → Store correto

API públicamantém os endpoints atuais.
PersistenceAdapterdecide o modo de armazenamento.
JsonFileStorefallback seguro enquanto o banco não estiver ativo.
PostgresStorepersistência real multi-tenant após migration validada.

Regra de segurança

Sem quebra de fluxo

  • Sem `FITCORE_DATABASE_URL`: continua em JSON local.
  • Com `FITCORE_DATABASE_URL`: Postgres entra somente após verificação.
  • A UI não mostra tabela, credencial nem detalhe interno.
  • Cada ação sensível deve registrar auditoria mínima.
