# GIFs dos exercícios

Esta pasta deve receber GIFs autorais ou devidamente licenciados para demonstrar os exercícios dentro dos treinos do FitCore Pro.

## Convenção de nomes

Use o slug do exercício como nome do arquivo:

```txt
/media/exercises/0024-barbell-bench-front-squat.gif
/media/exercises/0026-barbell-bench-squat.gif
/media/exercises/0289-dumbbell-bench-press.gif
```

O mapa usado pela interface fica em:

```txt
apps/site-static/exercise-media.js
```

Enquanto o GIF ainda não existir, a interface mostra `GIF pendente` e mantém a explicação textual do exercício.

## Regra de licença

Não enviar GIF baixado de app, marketplace, rede social ou banco de imagens sem autorização clara. Para produção, usar somente:

- GIF autoral;
- mídia licenciada para uso comercial;
- mídia criada internamente;
- mídia com permissão documentada.
