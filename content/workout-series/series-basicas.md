# Séries Básicas de Academia

## O que é uma série?

Uma série é um conjunto de repetições de um exercício.

Exemplo:

```txt
Supino reto
3 séries de 10 repetições
```

Isso significa executar o movimento 10 vezes, descansar e repetir o bloco até completar 3 séries.

## O que são repetições?

Repetições são quantas vezes o aluno executa o movimento dentro de uma série.

## O que é descanso?

Descanso é o tempo entre uma série e outra.

## Exemplo de treino iniciante

```txt
Agachamento livre: 3x10
Supino máquina: 3x10
Puxada frontal: 3x10
Elevação lateral: 3x12
Abdominal: 3x15
```

## Regra de segurança

Carga não deve ser aumentada se a técnica estiver ruim.
