# DESGNER Visual QA

## Source compliance
- [ ] Read `DESIGN.md` and `skills/desgner/SKILL.md`.
- [ ] Reference Lock exists.
- [ ] No undocumented global visual rule lives only in code.

## Token integrity
- [ ] New UI uses semantic project tokens/variants.
- [ ] No unexplained hardcoded color.
- [ ] No arbitrary radius/shadow.
- [ ] Spacing follows the existing scale.
- [ ] Dark/light hierarchy remains equivalent.

## Composition
- [ ] Primary user action/reading path is obvious.
- [ ] Visual weights are intentional.
- [ ] Not everything is rendered as an equal card.
- [ ] Decorative elements have product/brand purpose.

## Responsive
- [ ] Mobile checked.
- [ ] Intermediate/tablet checked when relevant.
- [ ] Desktop checked.
- [ ] No accidental overflow/clipping.
- [ ] Tables/charts have a mobile strategy.
- [ ] Touch targets remain usable.

## States
- [ ] Focus-visible.
- [ ] Hover/pressed/selected where relevant.
- [ ] Disabled.
- [ ] Loading.
- [ ] Empty.
- [ ] Error.
- [ ] Success/warning where relevant.

## Accessibility
- [ ] Keyboard path.
- [ ] Labels/errors.
- [ ] Contrast.
- [ ] Non-color cues.
- [ ] Reduced motion.

## Anti-AI smell
- [ ] No generic visual motif without `DESIGN.md` justification.
- [ ] No fake metrics/testimonials/logos.
- [ ] No generic marketing copy in production.
