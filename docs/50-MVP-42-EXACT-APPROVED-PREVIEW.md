# MVP-42 — Visual aprovado reproduzido em Next

Este gate substitui a landing e o dashboard por componentes Next que reproduzem o preview aprovado do FitCore Pro.

## Mantido
- API existente
- sessão, RBAC e PostgreSQL
- rotas operacionais
- GIFs internos publicados em `/media/exercises/`
- landing pública separada do console

## Entregue
- landing premium com hero, mockup do produto, cards e IA
- dashboard de dono/gestor com sidebar, KPIs, fluxo, agents, treino do dia, biblioteca, pendências, evolução e segurança
- CSS isolado em `exact-preview.css` para não quebrar rotas já existentes
