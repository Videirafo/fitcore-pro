# 03 - wger

O wger será usado como motor fitness open source do FitCore Pro.

## Responsabilidades do wger

- exercícios
- treinos
- nutrição
- peso
- medidas
- fotos de evolução
- API fitness
- app mobile base

## Onde ficará

```txt
upstream/wger-docker
```

## Regra

Não alterar o core do wger no começo.

Primeiro integrar usando API.

## Próxima etapa técnica

Clonar o Docker oficial do wger dentro de `upstream/wger-docker` e subir a base limpa antes de criar integrações próprias.
