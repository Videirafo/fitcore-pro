# FitCore Design Intelligence — fontes governadas

Issue: #7.

As referências Startora, Uiverse, 21st.dev, React Bits e Aceternity entram como inteligência visual, não como segundo design system.

Regras:
- `REFERENCE`: aprender hierarquia, composição, densidade, navegação e motion sem importar código;
- `ADAPT`: traduzir o princípio para tokens, CSS e componentes FitCore;
- importação de código exige revisão individual de licença, dependências, bundle, acessibilidade e mobile;
- nunca usar `@latest` automaticamente em CI/agentes;
- fluxo operacional prioriza velocidade e legibilidade sobre efeitos;
- qualquer motion deve respeitar `prefers-reduced-motion`.
