# LGPD - FitCore Pro

O FitCore Pro pode lidar com dados pessoais e dados sensíveis, como:

- medidas corporais
- fotos de evolução
- informações relacionadas à saúde/fitness
- histórico de treinos
- dados de pagamento
- dados de acesso

Antes de uso comercial, revisar:

- consentimento
- finalidade
- retenção de dados
- exclusão de dados
- portabilidade
- segurança
- logs de auditoria
